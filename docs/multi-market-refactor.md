# 日本市场标准接入方案

## 本次范围

仅接入日本股票市场及模拟交易。复用项目已经支持多个市场的页面、接口、
策略、研究、行情与模拟执行链路。日本的代码、数据源、日历、时段、交易
单位及交收限制进入现有适配层。日本实盘接入不在范围内。

保留其他市场功能、用户级资产汇总、账户归属、资金及缓存口径、用户别名、
现有 T+1 与时间处理。本次不修复旧系统 bug，不借适配重做通用账本或
强制把用户账户拆成各国家账户。若旧问题妨碍接入，先记录影响与依据，
不得自行扩大范围。

现有日股专用页面、卡片和独立业务路由属于本次错误接入方式，需在通用
链路完成迁移验证后移除。合理的日本数据、代码与规则适配保留并复用。

## 接入顺序

1. 对照现有 HK/US 等市场接入方式，逐项列出 JP 缺少的注册和上下文
   透传。只补日本入口，保持原市场行为。
2. 数据与研究：将已有日股数据接入通用股票池、特征、训练、推理、策略、
   回测与分析链路；数据版本和日期口径可核对，不增加国家专用业务系统。
3. 模拟交易：复用通用订单、持仓、成交、资金和调度流程，通过适配器
   执行日本规则。不能为接入简单放开旧模拟器的 JP 禁用检查。
4. 前端：在原有市场选择器直接选择日本，复用同一控制台和各业务页面；
   删除按国家切换整页/独立业务系统的 JP 配置和组件。
5. 迁移：先备份现有 JP 会话，保留账户、模型、持仓和交易历史；验证
   通用链路与旧 JP 会话映射、账目和重启恢复后再切换和删除旧执行器。
6. 验收：CN/JP 同页面、同功能；其他市场行为保持；真实日本日线完整
   链路通过。分钟/实时共用接口用明确测试数据验证，真实源缺失时报告
   不可用，不用日线冒充实时。2016–2018 历史交易单位缺失仍明确阻断。

## 每批 Review

改动 → 测试 → 完整 diff review → 修正 → 复查 → 提交。前端改动需
typecheck；后端按仓库流程提交推送并在本机同步重启。Review 检查改动
是否只为 JP 接入所必需、是否改变旧市场规则、是否另建国家业务系统、
是否保留原有账户和历史。只提交代码、测试和文档，不提交数据集、缓存、
密钥或本机配置。
