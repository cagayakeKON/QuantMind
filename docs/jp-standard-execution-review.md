# 日本市场标准执行路径收敛记录

审查基线：`master@913915e6`。本文记录标准执行路径的逐轮修正与独立审查，不将代码审查和隔离测试当作真实在线全链路验收，也未合并到 master。

## 为什么撤回此前实现

此前实现把原生 JPY、按日期交收、资金来源、公司行动和不可变发布一致性组合成了另一套执行协议。公共 URL 相同，不能证明底层仍是原 US/HK 执行模式。`DecisionExchange`、独立现金 runner、带属性的 float、日期检查点和 JSON 默认模型标记均超出了本次仅做市场接入的约束。

本轮先读取 master 的实际规则，再撤除这些协议，保留日本数据与市场规则的接入。没有将原市场的既有行为当成 bug 顺便修改，也不把撤除的保证冒充为新路径已实现。

| 领域 | master 的实际规则 | 本轮日本接入 |
| --- | --- | --- |
| 回测与优化 | 原 Qlib 策略、Exchange、Position、报告及优化任务 | 正常初始化的 JpExchange 接入报价、费用、交易单位与日历；撤独立现金执行器 |
| Strategy Lab | 原 QlibProvider、SimpleBroker、SDK 运行 | 日本 provider 与交易规则进入原入口；不要求日期现金上下文 |
| 模拟账户 | 用户账户 base_currency、共享账户 ID/现金台账及用户级汇总 | 沿用原金额口径，默认 CNY；没有新增 FX 或 JPY 子账 |
| 模型默认选择 | 每用户一个 SQL is_default=true | 日本遵同一 SQL 规则；不用 metadata.market_default 替代 |
| 回放 | 原信号/代码、提案/确认、止损与普通账户 | 日本日线、日历、交易单位；无日期现金检查点协议 |
| 既有原生日元状态 | 此前适配产生，不能解释为普通开户资金 | 保留只读，禁止重置、恢复成 CNY 或继续写入；不迁移、不删历史 |

原 base_currency 数字规则不等于真实外汇换算。原 Qlib 复权持仓也不等于原生现金交收、零股或特殊公司行动处理。实盘、分钟/实时行情以及待补历史交易单位仍按能力说明限制。

## 测试迁移与撤除边界

Qlib 逐函数分类见 [jp-standard-test-retirement.md](jp-standard-test-retirement.md)。其余分类如下；“迁移”只表示验证当前公共功能，不表示保留旧私有协议的全部保证。

| 旧覆盖 | 处理与当前验证 |
| --- | --- |
| dated cash backtest、独立 cash oracle、交收/资金来源 journal | 撤对应执行协议测试；交收和资金来源延期独立设计，没有伪造平替 |
| 模拟 checkpoint/cycle、回放现金与迁移协议 | 撤私有状态断言；标准 PG/Redis 测试验证普通成交、现金流水、持仓批次、aware UTC、回放恢复和旧 native 只读保护 |
| 证券 master、历史单位、ticks、涨跌停、日线缺失、退市 | 保留数据规则覆盖，供正常 matcher、Qlib 和 SDK 使用 |
| 手动预案/执行 | 迁到标准模型/信号/策略准入、预案哈希、任务持久化与恢复、股票池、基本面、worker 终态测试 |
| hosted cycle/readiness/lifecycle | 迁到 SQL 默认模型、普通 completed 信号批次、Tokyo 时段、作业锁、重复任务及 noop；不保留独立日期 CAS |
| sandbox 日期账户/执行 | 原 SDK 缓存和订单信封；实际 worker intent → consumer → PG 成交/台账；保留旧 native 写入拦截 |
| preview/runtime 日期连续性 | 不再要求启动日期固定或逐交易日现金 checkpoint；验证普通运行恢复和旧状态只读 |
| 推理与研究 provenance | 保留发布固定、覆盖范围、禁止 JP 伪造模板预测、真实 writer、JSONB 来源、归因/研究观察数据；fixture 脱离现金协议 |
| 公共数据面板/终端/成交读取 | 普通 UUID SQL fixture；保留 JP 数据读取与原用户共享历史、普通 symbol 筛选缓存；不新增国家账户协议 |
