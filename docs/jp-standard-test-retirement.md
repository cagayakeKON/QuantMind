# JP standard Qlib test migration matrix

Scope: Qlib, JP strategy/backtest and mixed research/data tests. Simulation/Replay retirement is documented separately. Original test functions were extracted through AST and compared individually with current functions, followed by deleted-module import/caller checks. No whole directory was removed.

The listed replacements test specific standard signal, pool, fundamental reader/filter, label, analysis, position, research and export behavior. They do not establish semantic equivalence with the retired executor. Independent cash settlement/ledger, DecisionExchange and private context protocols retire.

Inherited behavior: the original runtime does not auto-compute IC for a SimpleSignal dict; original FactorAnalysisService IC/groups are tested independently against actual published labels. MarketState missing-volume behavior is preserved. Standard adjusted-share Portfolio does not provide the retired raw-share/settlement guarantees. The former context rejected future reads and unknown/missing fields; standard custom code uses Qlib APIs directly and is not guarded against future queries. Missing/unknown native expressions can produce an empty completed run or the original Qlib error; no universal explicit-failure guarantee is claimed. Pure published fundamental/style/provenance readers retain the validations tested in their retained cases. Only strategies conforming to Qlib API are supported.
