# 日本市场接入与能力说明

分支：`codex/japan-market-adaptation`；基线：`master@913915e6`。此前“全部功能完成”的结论已经撤回。本分支已撤除额外执行框架；下文描述标准接入契约和能力边界，逐轮审查与验证见 [jp-standard-execution-review.md](jp-standard-execution-review.md)。代码审查及隔离测试不等于真实在线全链路验收。

## 接入契约

前端通过全局日本市场选项进入原训练、推理、AI 向导、Strategy Lab、回测、优化、模拟交易、托管、持仓、历史和研究页面。手动任务、部署向导和个人中心复用原表单，不再要求独立的日期、发布版本或资金来源执行上下文。

数据通过 LOCAL_MARKET_PROVIDERS、DataHub、StockCodeUtil、市场配置和 RD Agent MarketAdapter 接入。数据层为 `72030.JP` / `216A0.JP`，DB/API/前端为 `JP72030` / `JP216A0`，Qlib 为 `jp_72030` / `jp_216A0`。四位裸代码必须携带 JP 上下文，不能影响原港股识别。

回测接回原 Qlib 生命周期、策略构建、订单、Position、报告和优化流程。JpExchange 经原父类正常初始化，因子使用普通数值；日本报价、涨跌停、费用及按日期交易单位通过该扩展点提供。原 US/HK/CN 仍使用原 Exchange 配置。已撤除独立现金 runner、DecisionExchange、带属性的 float、延迟执行注册和对应 checkpoint 状态机。测试覆盖的策略不代表任意第三方 Qlib 策略都已验证。

Strategy Lab 通过原 QlibProvider 和 SimpleBroker 运行；日本 provider 提供日历、股票池、数据版本和交易规则，原市场没有新配置时保持原行为。日频 SDK 的历史、指标、买卖及辅助运行使用共用入口。

默认模型遵守原 `(tenant_id, user_id) WHERE is_default=TRUE` 唯一约束，即每个用户一个默认模型。JP 不再使用 metadata.market_default 替代 SQL 标记。选择 JP 默认模型会按原规则替换该用户此前的默认模型；旧 JSON 标记不会自动转成新默认选择。

托管仍按原入口绑定用户当前 SQL 默认模型的单一推理批次，修改默认模型后会采用新的默认模型。页面市场选择不新增每市场独立默认模型或独立托管账户，也不把这条既有绑定规则改成 JP 私有协议。

## 模拟账户与旧状态

原系统模拟金额按用户账户 base_currency 计算，市场币种用于行情资料；没有现成汇率换算链路。本次 JP 接回原共享账户、现金流水、持仓、Redis 和按用户汇总规则。默认基础币种仍为 CNY，不能把共用账户显示成独立 JPY 账户，也不能声称这些数值已经自动换汇。

JP 日线撮合读取最新可用原始行情，沿用普通订单、限价、费用和可卖量入口。没有实时/分钟行情，不将日线标成实时成交证据。托管使用原周期和调度，JP 日期及时区由市场配置提供；不再固定启动时的独立执行日期或要求持仓账户逐日提交日期检查点。瞬时时间仍使用原 aware UTC / TIMESTAMPTZ 规则，不伪造为历史开盘时间。

普通回放在当日提案、止损和成交前按发布的拆并股因子调整持仓数量、可卖量和单位成本，现金和总成本保持不变；预览后确认不会重复调整，收盘快照保留调整日期以支持缓存恢复。当日买入已经是新股数口径，不再次授予拆股股份。配股价格因子不用于增加股份；反向拆股产生不足一股时，需要真实零股处置资料，缺少资料会明确拒绝执行，不假造现金补偿。

已有原生 JPY 账户、日期状态和回放来源保留只读。读取、重置、恢复及执行不得把旧 JPY 数字解释为共用 CNY 开户资金。兼容旧列存在或不存在的库；不自动迁移、清资金、删历史表或重新成交。源码撤除新增状态模型/建表声明，不会删除数据库已有数据。若要保留原生交收及资金来源能力，应独立设计并审查迁移和退出方案。

资金卡和图表使用原用户级基础币种汇总。JP 页面不接受退休原生 JPY 图表消息；属于共用 CNY 汇总的旧市场消息仍按原规则接收。这不是跨币种真实资产核算。

## 已有本地数据与同步

源快照位于 `../量化/data/jquants_standard/20261001/jquants.duckdb`。已导入 2016-10-03～2026-09-30 的原始普通股日线、逐日主表、现金交易日历、估值和 TOPIX 价格指数；研究复权价格与执行原始价格分开。已发布 Alpha158 日线因子，读取目录为 `6_ml_datasets/l1_factors/dt=YYYYMMDD/data.parquet`。

源快照、已发布数据、Qlib 缓存、模型及私有环境配置均不提交 Git。

空环境可在管理后台配置并启用 J-Quants 数据源后直接同步，首次按所选 `days` 窗口下载交易日完整核心日包，无需先导入或提供 `--seed`。后续同步保留历史并补齐缺失交易日；没有开放交易日的窗口明确报错，不发布空版本。已有发布会先恢复到独立缓存，损坏发布会拒绝同步，避免覆盖历史。

已有本地历史快照也可选择导入（已有数据无需重复）：

```powershell
python backend/scripts/import_jquants_snapshot.py --source 'C:\Users\KONIMAS\Desktop\project\量化\data\jquants_standard\20261001\jquants.duckdb' --destination data/quantjp
```

特征发布根目录为 `QM_QUANTJP_DATA_DIR`，不是当前 `versions/{version}` 目录：

```bash
python backend/scripts/build_jp_features.py --root /data/quantjp --workers 2 --batch-size 64
python backend/scripts/quantjp_daily_sync.py --days 5
```

原始行情的有效版本为 raw-current.json，训练/推理研究发布为 current.json。原始同步只推进 raw 指针；特征/Qlib 更新关闭、超时或失败时，已有可用研究版本保持，任务报告研究待更新。K 线、证券搜索和终端行情显式读取原始发布，研究 reader 保持研究发布。完整特征发布成功后才推进研究指针；仅部分日期的特征构建不能替换完整研究发布。后台“同步后更新特征与 Qlib”及定时同步采用相同发布根和最新原始发布解析。JP 特征生成失败时任务标记失败，不因原始行情成功就报告完整任务完成。网络下载需私有 `JQUANTS_API_KEY`；无 Key 不开展真实在线同步。调度只服从用户保存的 Redis 配置，未配置保持关闭。

相关变量：`QM_QUANTJP_DATA_DIR`、`QM_JQUANTS_CACHE_DB`、`QM_JP_TRADING_UNITS_FILE`、`JQUANTS_API_KEY`。本机通用 Compose、启动脚本、认证和日志修改已拆到独立本地分支 `codex/jp-review-local-environment`（`ad90f19d`），不属于日本适配提交；本机文件仍保留可用。

远程训练沿用原节点类型与 SSH 编排器。该节点的 `quantdb_dir` 必须指向节点已有的完整 JP 发布根目录；只读探针检查 manifest、因子、日历和必需列，并把实际节点版本与路径固定到本次任务。原中心因子目录就绪、请求区间覆盖及已发布映射的准入规则仍然适用，节点有数据不等于可以绕过中心准入。该配置不代表系统会自动同步 JP 数据到节点，缺失或不完整发布不能靠中央节点的本地数据冒充可用；未开展真实 SSH 或远程训练验收。

## 能力边界

| 能力 | 当前范围 |
| --- | --- |
| 日线、股票池、训练、单模型/融合推理 | 公共入口；本地/远程节点读取各自完整 JP 发布并预检，缺数据不造结果；训练支持 open/close 标签 |
| AI 策略、完整因子挖掘 | 共用适配器；LLM 配置不在本次范围，不要求完整 LLM 实跑 |
| 回测与优化 | 原 Qlib 日频路径，JP open/close 报价、费用、交易单位、TOPIX；多空与杠杆沿用原策略、Exchange 和 MarginPosition，属于模拟假设，不能作为真实借券可用证明 |
| 模拟、托管、手动交易 | 原共用基础币种账户和日线撮合；没有原生 JPY 交收/差金交易状态机 |
| 历史回放 | 原信号/代码、自动/手动、止损流程；JP 日线、日历和交易单位接入，验证见本轮记录 |
| Strategy Lab | 原日频执行和风险接口；没有分钟行情或真实开盘队列 |
| 研究、归因 | 预测实际来源版本及 factor_field_sources，确切日期，不用训练旧版本解释新预测 |
| TradingAgents | JP 本地行情、指标、已有估值；新闻依赖原供应商环境/网络，未完整在线 LLM 验收 |
| CN 专用终端表达式/AI 回测及 SSE 日历工具 | 原 US/HK 也未接入，不计为本次公共多市场功能完成；JP 策略使用公共回测与市场日历入口 |
| 实盘券商、分钟/实时行情 | 本次不接入 |
| 原生 JPY 交收、资金来源、特殊公司行动 | 从本次标准接入撤出；需独立设计审查，不宣称真实账户等价 |
| TOPIX 风格归因/量比能力 | volume 输入不足，不能宣称完整支持 |
