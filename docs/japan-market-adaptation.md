# 日本市场标准接入与能力说明

分支：`codex/japan-market-adaptation`；审查基线：`master@913915e6`。

2026-10-04 的外部 review 发现实际接入遗漏和资金边界缺陷，此前“最终验收完成”的结论撤回。本文件描述当前公共入口和能力边界，不将历史测试通过等同于所有功能可用。当前分支不合并。

## 接入方式

前端使用全局日本市场选择，沿用原训练、推理、AI 策略向导、Strategy Lab、回测、优化、模拟交易、托管、持仓和成交历史页面。个人中心也复用公共日期输入/账户重置表单，不将 CNY 设置当作 JPY 初始资金；原生日期账户不提供无资金来源凭证的 OCR 持仓同步。后台沿用原市场数据与特征字典管理入口，不创建日股专用交易页面或业务 API。

后端通过 `LOCAL_MARKET_PROVIDERS`、DataHub、`StockCodeUtil` 和 RD Agent `MarketAdapter` 提供日本数据与规则。日本模块提供证券资料、日历、原生现金规则和数据快照；订单、策略调度、回测生命周期和报告使用共用实现。日股新增的日期现金执行、检查点与原生币种台账属于框架扩展，需要独立验证，不能仅凭 API 一致认定与其他市场能力相同。

数据层为 `72030.JP` / `216A0.JP`，DB/API/前端为 `JP72030` / `JP216A0`，Qlib 为 `jp_72030` / `jp_216A0`。完整保留 J-Quants 五位标识和字母；四位裸代码仅在明确 JP 上下文中转换，避免误认港股。

AI 向导的日本股票池直接从注册的日本发布快照查询，不查询 A 股 PG 表；数字与趋势条件使用真实日本字段，缺少字段明确失败。生成配置采用日本 provider、`region=us`、TOPIX 基准。原市场股票池查询路径保留。

## 资金与时间边界

用户账户根 ID 仍是 `sim:{tenant}:{user}`，没有新增国家账户根表或改变原市场共享投影规则。日本原生资金与完整资金来源保存在根的 `market_state.JP`；日本流水、持仓批次及成交投影使用 `sim:{tenant}:{user}:JP` 作为台账范围，流水币种为 JPY。这是台账范围标识，不是另一条独立交易流程。

日本成交不得覆盖根账户 CNY 现金、初始权益或原市场市值。原市场冷恢复只能读取其原台账范围，不混入日本持仓。日本账户从已提交的固定版本检查点恢复，不从 Redis 余额猜测资金来源。周期权益 worker 不重估日期现金账户、不将 JPY 缓存投影到 CNY 根；日本估值由固定日期的共用执行周期完成。

原有非日本输入的按用户汇总算法和重置清理规则保持原行为。新接入的日期现金账户不参与原 CNY 快照与成交统计直接相加。日本资金概览、日/月盈亏、每日权益和成交统计通过原公共接口的 market=JP 参数读取原生检查点，前端标注 JPY；缺少可靠历史基线时标记不可用，不套用用户级 CNY 基线。日本重置不改写原市场初始资金设置。本次未实现自动跨币种换汇，也未把既有汇总快照当作已完成 CNY/JPY 合并核算的证明。历史日本成交若缺少新的原生台账范围凭证，明确要求审计迁移；不自动猜测或修复被污染的原资金。

同一笔历史成交的检查点和标准 `sim_trades.executed_at` 使用同一模拟开盘时刻，aware UTC，JSON 带 `Z`；标准成交投影、资金流水和持仓开仓时间使用相同 UTC 时刻。真实处理时间由原表创建时间、订单接收时间保留作审计。原市场默认时间行为不变。

使用现有 JWT 与租户/用户授权。通过原页面生成请求，不调用已移除的日股私有会话执行接口。

| 回测与优化 | 原回测入口与标准策略模板；配置携带 JP 模型及发布版本 |
| 模拟账户上下文 | `GET /api/v1/simulation/execution-inputs?market=JP` |

`jp_cash_topk` 已停止作为新回测策略类型，不能再用于创建任务；旧结果仅保留只读兼容展示。现有 `/simulation/jp/...` 会话执行 API 已移除，不作为使用说明。原历史会话迁移保留审计凭证，不在本次 review 修复中推进或重置生产账户。

回测读取实际 JP 模型 `pred.parquet`，按既有标准策略生成订单，日期现金撮合使用原始开盘价；报告固定价格/训练数据版本、预测 SHA-256、实际费用、JPY 权益及 TOPIX 价格收益。股票池、持仓和指标由原公共流程处理。

融合推理与单模型推理同样读取日本原生分区数据，显式传 JP 市场，固定一次推理的发布版本；源模型必须属于 JP 原生因子源，缺少模型字段时失败，不填造日本缺失字段。激活自动推理使用日本发布现金日历及 Asia/Tokyo 时区，不回落 XSHG。

## 持续托管与共用研究入口

托管采用“已发布日线延迟模拟”：计划日期与实际模拟执行日期分别保留，最多执行计划日期之前已经发布完整原始日线的交易日，不伪装为当前盘中撮合。每轮重新校验对应执行日的推理批次、模型版本与预测哈希。跨新发布时先证明已消耗的原始行情、证券资料、既有现金日历（包含交收日期）与单位资料不变，再在原检查点中保留审计来源并推进版本；历史修订或规则输入变化阻断，不重建现金、持仓或旧成交。费用配置保持。任何既有历史修订或单位文件摘要变化都会阻断自动推进，尚未实现未来单位资料追加的细粒度等价证明。证明按日期分区流式执行并缓存不可变发布摘要；首次新版本的冷扫描未验证生产十年数据规模耗时。每周或每 N 日调仓通过共用账户准备阶段补齐中间交易日的交收、公司行动与收盘估值，无信号日仍完成账户日周期。缺少事件/价格时阻断，不取消连续交易日校验。成功的日本回测通过原策略存储标记已验证，手动模拟执行仍走原准入检查。

Strategy Lab 原提交入口传 options.market=JP，worker 通过注册的 provider 使用日本发布日历、Alpha158 特征与 TOPIX；当日 on_bar、默认 history 与持仓成本均采用原始价格，研究复权历史显式指定 history(adjust="qfq")；原 Lab 循环通过共用日期现金执行器撮合普通股现金订单。T 收盘信号在下一交易日原始开盘价执行，结果标注 dated_cash、JPY 和固定发布版本。通过当前注册 provider 的实例级股票池名使用 ctx.universe="all"；原 CN 白名单不变。当日 on_bar/快照只接受确切日期且当日有效证券，历史 history 查询仍可返回 as-of 旧记录。首次 all 解析通过公开数据接口，不假设懒视图已经注册。非 day 频率明确拒绝。最后一天尚未执行的信号只告警，不伪造成交。SDK 盘中风险订单/止损当前不支持，明确拒绝；这与下表的回放 code 模式限制分别声明。

TradingAgents 日本请求通过注册市场路由读取日本本地行情、技术指标及已有估值字段，不进入 A 股供应商回退链。个股新闻用统一工具转换为 Yahoo 的 7203.T / 216A.T；新闻仍依赖既有供应商、运行环境与网络，未执行真实在线新闻或完整 LLM 分析。本机镜像目前缺少既有新闻模块依赖 stockstats，相关能力明确不可用；本次不修改原供应商依赖环境。未发布的历史财务报表及中国专属资金/信号工具明确返回不可用。

公共参数验证允许 JP；指定 K 线日期范围时保留完整区间，未指定日期时仍采用默认最近 120 根。StockCodeUtil 保留 jp_72030 的 Qlib 格式；未知市场和 BC 仍沿用原 CN 回退。无行为变化的 Standard 组件改名已撤回。

## 能力与明确限制

| 能力 | 当前口径 |
| --- | --- |
| 日线研究、训练、单模型/融合推理 | 日本发布数据及现金日历；缺数据阻断；训练仅支持本地节点，公共探针和提交拒绝远程 JP |
| AI 策略、完整因子挖掘 | 接入共用市场适配器；不包含 LLM 配置，不要求运行完整 LLM 挖掘 |
| 标准策略回测、优化、模拟与托管 | 普通股、现金做多、原始日线开盘；固定日期/发布版本；佣金及滑点可设 |
| Strategy Lab SDK 回测 | 日本发布 provider + 共用日期现金执行，普通股现金做多；盘中风险订单不支持 |
| TradingAgents 投研 | 日本本地行情/指标/估值接入；新闻依赖环境/网络，未运行完整在线 LLM 分析 |
| 历史回放止损 | 暂不支持；共享页面禁用输入，并剔除用户/模板止损参数；后端继续拒绝非零值 |
| 回放 code 模式 | 暂不支持；需要相应数据和执行适配器，不伪造能力 |
| 日股实盘券商、做空、杠杆 | 本次不接入 |
| 分钟、盘中、实时与开盘排队 | 当前本地日线不能提供，不能据此宣称实盘路径可用 |
| TOPIX 风格归因、动态量比仓位 | TOPIX volume 输入缺失，完整量比规则明确拒绝；关闭 dynamic_position 的现金策略不受此限制 |
| 股息、税费、权利/退市特殊处置 | 缺完整事件资料；受影响持仓阻断，保留原状态 |

标准回测与 Lab 延迟订单显式携带信号日股数基准，在执行日拆合股后通过同一现金规则转换；成交回调使用执行日股数，审计保留信号数量。没有基准声明的既有订单保持原行为。合股产生小数股或需要非整手卖出的情形明确阻断，零股处置尚未实现，不能把清仓静默改为部分卖出。JP 做空准入检查实际策略类型、配置和实例，不读取 CN 融券池。

托管周期成功后以身份校验和 Redis CAS 更新同一 runtime，沙箱和原页面读取新日期及版本；不会把启动日期固定到下一周期。PG 已提交而 runtime 发布失败时，只能根据匹配父 runtime、周期、策略、版本和市场台账范围的检查点恢复上下文，不重新成交。手动与沙箱预览逐交易日投影交收和公司行动，保持只读。

新回放会话保存内容寻址的不可变模型预测快照；模型追加后续预测不影响旧会话，快照篡改仍被摘要校验拒绝。旧会话只有在源文件仍与保存摘要相同时才可捕获快照，已变化的旧预测不能自动重建。

AI-IDE 沿原模板路由选择 JP 模型、股票池和原生字段参考，不套用 CN 的 ST、上市天数或指数池默认值；原市场模板保留。默认运行使用已发布现金日、原始开盘、JP 费用配置与固定模型，不回落 CN provider。研究和 SHAP 使用每笔预测记录的实际推理发布，而非模型训练版本；同日补推可有多版本，批量特征按逐股票来源读取。快照复用训练/推理的 `factor_field_sources`，保持模型特征顺序，只接受确切输入日；不拿旧日期特征解释新预测。旧预测若未记录来源，保留分数但不猜测价格、因子或 SHAP 输入。TradingAgents 报告通过原注册行情入口按分析日期读取公司名，避免未来名称污染历史报告。

新训练在实际读取前固定发布，并在原预测产物保存入口记录训练 run 来源；没有未来日历时不虚构信号执行日。训练历史分数的 split/fold 模型输入未保存，当前 SHAP 明确不可用，不能套用日常推理的预处理；价格和因子仍可按已记录训练来源研究。

停止托管后，手动执行表单可显式“选择最新发布”，并保留账户费用。选择本身只读取输入，不重置资金或持仓；预案和执行前仍由已有检查点连续性证明决定能否推进，不兼容历史修订继续拒绝。运行中的发布固定，不能由表单切换。

日本资金图表的 HTTP 账户响应包含认证用户、租户、市场、币种和模拟模式；跨 JP 账户范围的迟到请求不能覆盖当前图表。`chart_update` 对 JP 同样要求匹配这些来源标签，缺失或冲突时拒绝；目前仓库没有该消息的生产端，不能宣称已验证完整实时推送链路。

当前执行实现包含注册现金回测、日期检查点、`DecisionExchange` 等框架扩展，以及 JP 的 `metadata.market_default` 协议。这些实现仍需作为架构变更独立评审；复用公共页面/API 不等于与 US 的原 Qlib 路径等价，也不证明任意 Qlib 策略兼容。下列未支持能力仍保留，四项缺陷修复不代表“全部功能可用”。

历史现金交收采用 2019-07-16 前 T+3、之后 T+2。差金交易通过资金来源约束校验。同一证券日成交量不能超过观测日成交量；该上限并不能证明开盘流动性。停牌、缺价、零量、无法确认执行或限价条件时不填充成交。滑点和 tick 舍入后的最终价格必须落在当日观测高低价与可确认的涨跌停边界内，越界拒绝成交；涨跌停资料依据 [JPX 官方规则](https://www.jpx.co.jp/english/equities/trading/domestic/06.html)，缺少特殊扩幅资料仍按数据缺失边界阻断。

2016～2018 逐股票交易单位资料由用户后补。2018-10-01 前缺少可靠资料时阻断相关执行，不回填今日的 100 股单位。单位资料在导入时复制到不可变发布并保存 SHA-256，后续修改外部文件只在新发布生效，旧版本不读取新的外部资料。默认配置路径不存在时，报告历史单位未提供，不阻断现代已有单位规则；文件存在但非法时导入失败且有效指针不动。交易单位文件为 UTF-8 CSV：`symbol,valid_from,valid_to,lot_size,source`，生效区间含首尾且不能重叠。
