## 确认与修正

- TOPIX 日行情按官方接口使用同一天的 `from` / `to`，不再发送被忽略的 `date`。同步的核心原子日包依赖在注册 provider、公共目录、请求、任务结果与原管理面板一致声明；估值为可选数据，未选不下载。没有真实在线同步或 API Key 请求。
- A 股股票终端的默认信号日、趋势、模型日期及上证 MA20 推理统计排除新增 JP 分数；原非 JP 聚合范围保留。公共成交记录从页面到 SQL 在分页之前区分 JP 与原非 JP 范围，缓存键与涉及 JP 的迟到响应也隔离。
- data-dashboard 的日本搜索、证券主表、行业、原始日线、估值、现金日历与原生 L1 字段经注册 provider 读取，返回实际发布来源。未发布财报等字段明确不可用。后台状态扫描识别 JP/japan，使用东京时区与真实日本发布、Qlib 目录，不回落中国目录。
- 股票终端的 A 股标签 AI 回测、表达式图表回测与上证 MA20 日历未实现日本能力，明确拒绝 JP 请求；没有借用 CN 结果宣称已接入。公共策略回测与日本现金日历入口保持可用范围。
- 有确切原始行与有效证券主表的停牌持仓保留准备阶段已调整的旧价格，记录陈旧估值，并保持不可成交。跨日准备、周期收盘、下一次回测决策及停牌日拆股账务共用这一规则；缺少行、主表或可靠价格仍拒绝。公司行动只调整一次。
- TOPIX100 tick 按 2014-01-14、2014-07-22 与 2015-09-24 分阶段生效；2016 年后的表不变。2010-01-04 以前没有可靠支持，明确阻断，不反向套用现代规则。
- 每日盯盘选择本次最新完整研究发布，并固定本次扫描来源。JP 同一所有者、脚本、参数、股票池、日期及发布的结果用 Redis claim 防止重复发布；失败释放本任务的 claim，失去所有权的旧任务不能清空新任务信号。历史辅助回测仍固定原版本，旧市场盯盘行为不重构。
- 研究列表携带逐股票观察到的分数与来源；特征接口核对 owned model/day 当前预测后固定对应不可变发布。列表读取后发生补推时返回 `PREDICTION_SOURCE_CHANGED`，页面清空旧特征并最多自动重读一次；再次变化时提示手动刷新。后端核对之后再发生补推也不会换掉本次特征来源。原市场请求协议保留。
- 旧拆股测试的 900 股是信号日数量，执行日 1:2 拆股后应为 1800 股；同步八项断言并新增价格、交收、现金与权益验证。普通 JP 报价拒单遵守现有 `success=false` 契约，验证无成交、资金或缓存写入。这九项失败属于测试契约失配，未修改产品交易规则迎合旧断言。

TOPIX 接口依据：[J-Quants 官方规范](https://jpx-jquants.com/en/spec/idx-bars-daily-topix)。历史 tick 依据：[JPX 第一、二阶段表](https://www.jpx.co.jp/files/tse/news/20/b7gje6000004313n-att/leaflet_english.pdf)、[第三阶段生效表](https://www.jpx.co.jp/english/news/1030/b5b4pj000000pvpf-att/English1.pdf)、[2010 年 arrowhead 交易表历史](https://www.jpx.co.jp/english/corporate/research-study/working-paper/b5b4pj000000i468-att/JPX_working_paper_No7.pdf)。2010 以前的限制指本实现未支持，不意味着市场不存在历史资料。
